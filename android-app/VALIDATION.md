- 官方 SDK 编译、APK v2/v3 签名验证通过。
- 32 项既有策略检查，以及 44 项新增 JVM 效率检查通过。后者覆盖标签合并、状态/过滤/详情/长度上限、旧 UI 裁剪及协议配对、图片移除、裁剪坐标映射、帧过期/目标说明/清理、厂商参数范围、模拟 SSE 用量去重及请求序列。使用校验和固定的 org.json 测试依赖，不将其加入 APK，不调用真实模型。

- 设备识别 `screenshot_capable=true`，本次无需重开无障碍；这只证明能力被系统识别，不证明实际截图成功。

- 最后的 `ui_selftest` 因前台仍是助手自身界面而安全拒绝，没有为完成测试绕过自身界面保护；动作后 UI 与重复动作保护仍需在设置保持前台时补做实测。

## 已通过

- 官方 Android SDK 构建、APK v2/v3 签名验证。
- 电脑侧 17 项策略检查：HTTPS、URL 凭据/参数限制、路径越界、符号链接越界、修改权限分类、输出截断等。
- 设备侧 11 项原生检查：路径隔离、HTTPS、工具 schema 唯一性、文件写入/编号读取、精确编辑、快照撤销、grep、glob、App UID 系统 Shell 等。
