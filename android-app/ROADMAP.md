# 定位与差异

当前是自研的轻量 Java agent，不是 Pi/DSH 的官方手机端，也不声称优于成熟手机 agent。
已知可定制性与体积小不等于可靠性、模型能力或完整 Linux 开发能力领先。

## 当前价值

- 用户控制源码、模型、会话和执行策略；能够针对自己的设备修复与优化。
- Android 原生执行层负责无障碍、多窗口、通知批准、任务生命周期与停止。
- 私有工作区与会话迁移适配个人既有项目；无内嵌 Linux/Node，资源占用较小但工具生态有限。

## 推荐方向（规划，不代表已经实现）

Android 交互/执行层 + 可替换引擎 + 用户的专用工作流。
先把执行、错误恢复、历史性能与权限交互做扎实；如果需求主要是编程和 Linux 工具，再评估嵌入 Pi/DSH 等成熟引擎。
不为“有差异”重复造所有 agent 基础设施，不为了功能列表贸然内嵌大体积运行时。

DSH Go 的本机模式安装 Ubuntu/Node/DSH，并由 Android 桥接提供手机操控；普通模式用无障碍。
PRoot 兼容的是用户态文件系统/系统调用路径，不启动新内核、不凭空获得 root。
其不打扰模式要求 Android 14+ 与额外通道，不能直接应用到当前 Android API 31 设备。
