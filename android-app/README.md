# Pocket Agent 原生 App

此项目把旧 Termux agent 的交互与运行服务迁入独立 Android App，不再需要启动终端、Python 服务或本机网页。
沿用原包名 `local.termux.agentbridge` 和签名，以更新方式安装原 Agent Bridge。

## 使用

1. 安装 `build/agent-bridge.apk`（1.2.0 的平板共享存储副本：`Download/pocket-agent-1.2.0.apk`；旧同名安装包可能为旧版）。
2. 在 App 设置中确认模型配置与云端处理许可，手动启用无障碍服务并允许设备操作。
3. 在“对话”页输入任务。默认先确认一次本任务的普通界面授权，之后继续执行；敏感操作另行确认。
4. 后台任务显示常驻通知。需要确认时可以在通知中直接允许/拒绝，不必返回助手；通知不可用时仍可回 App 确认。

不需要再次配对；原生 agent 在 App 内直接调用无障碍服务。旧版 loopback HTTP 默认关闭。
确认方式支持逐步询问、本任务授权、持续自动普通界面三档。持续自动需明确确认风险。
“高级：扩展免审批”单独控制本 App 工作区写改与 Shell，默认关闭；已识别的敏感命令和 `confirm_action` 仍需人工确认。
这些只是 App 内审批策略，不提供 root、系统全权限或免锁屏能力。风险识别是尽力而为，不是安全边界，不保证消除误操作与提示注入风险。
不得用它处理无人确认的付款、删除或敏感权限修改。紧急停止还会关闭扩展自动并恢复任务级确认。

## 1.1 性能调整

- 历史由后台线程查询，每页 16 条，提供“查看更早消息”和“回到最新”；不删除或改写历史。
- 长消息先显示预览；工具记录与旧版 work log 在点击时才创建详情。
- 流式刷新不再反复读取整段数据库或重建全部 Markdown。
- 首版仍非完整虚拟化列表；极长单条消息主动展开、大字体和更多设备矩阵仍需继续验证。

## 1.2 无障碍与视觉协同

- 无障碍默认发精简控件，动作后直接回传新 UI，相同场景复用并裁剪过时上下文。
- 独立授权的低细节截图作为补盲，默认关闭、默认每任务 3 次尝试，不保存图片且只发一轮。
- 视觉点击绑定截图、逐次人工确认并核对画面；变化时拒绝，不接受无来源像素 tap。
- 官方 DeepSeek Flash 使用非思考请求；设置显示实际 usage 和 UI 字符指标，不把字符节省当成 token 降幅。
- 无障碍能读什么、隐私限制和完整流程见 [`ACCESSIBILITY_VISION.md`](ACCESSIBILITY_VISION.md)。

## 迁移内容

- API 地址与模型配置；密钥导入后使用 Android Keystore AES-GCM 加密，不放在 APK、共享文件或聊天中。
- 旧数据库的会话消息、摘要、元数据（保留旧版命名空间），以及符合大小限制的工作区文件。
- 旧会话以“旧版 · …”显示，默认新会话不混入旧 QQBot 对话。
- 旧 Termux 项目和数据库不删除；部署前备份位于 `~/agent-backups/native-app-20261112-v1/`。

`migrate_from_termux.py` 通过已授权 ADB 管道把数据直接送到 App 私有 ContentProvider；该入口还要求调用者为 shell UID 2000。
普通 App 不能调用迁移或测试入口。开发者自测只检查沙箱与工具，不能据此跳过用户的系统权限/云端同意。

## 原生能力与边界

- 模型：兼容 OpenAI 风格的 HTTPS 流式工具调用；不跟随重定向转发密钥。
- agent：会话持久化、历史摘要、工具轮次上限、可查看执行记录、取消请求、进程中断提示、前台任务通知。
- 无障碍：状态、App 列表、同一 App 多窗口观察、控件点击/长按/输入/滚动、坐标手势、导航。
- 文件：工作区读写、精确编辑、快照撤销、列目录、grep、glob、系统文件选择器导入、会话 Markdown 导出。
- Shell：`/system/bin/sh`，使用 App UID，不是 root，也不是旧 Termux 环境。支持超时、后台日志和任务管理。

**不能把 Termux 的 Linux 工具链直接搬进普通 APK 沙箱。** 旧 Python 脚本作为文件保留，但不保证可运行；本版未内嵌 Python、pip、编译器或 proot。
也不能任意访问其他 App 私有目录。此版没有本地 OCR、语音输入、Shizuku，或开机自动操作设备；云端截图视觉必须单独授权。
Shell 和文件工具是协作执行器，不是运行恶意代码的安全容器。停止进程不保证能回滚外部副作用或杀死所有自行脱离的孙进程。

任务、相关历史、屏幕文字和工具输出会发给配置的模型服务商，并可能进入本地会话。密码控件、本 App 界面和锁屏受到阻止。
无障碍不是 root；自绘 UI 可能不可读。系统可能回收后台进程，不承诺永久存活。卸载 App 会删除私有数据。

## 构建

Java 11+，官方 Android SDK Build Tools 34 和 android.jar：

```sh
python3 build.py --tools /path/to/build-tools/34.0.0 --android /path/to/android-34/android.jar
```

签名私钥保留在构建电脑 `~/.local/share/termux-agent-bridge-signing/`，不随 APK 分发。
运行测试和设备验证记录见 `VALIDATION.md`。
