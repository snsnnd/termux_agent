# 1.1.0

- 修复长历史在主线程全量查询/创建视图造成的明显卡顿路径；改为异步 16 条分页、长文本预览和延迟展开工具记录。
- 流式更新仅更新可见回复文本，不随每个分片查整段历史。
- 默认本任务界面授权，执行结束、取消或进程退出时失效；新增持续界面自动与独立的工作区/Shell 扩展自动选项。
- 通知提供允许/拒绝/紧急停止；批准携带一次性审批 ID，过期 ID 不会批准新动作。
- 增加敏感控件/应用/部分 Shell 命令的尽力识别，以及不可被自动审批跳过的 `confirm_action`。
- 仍不能保证识别所有危险动作；自动模式不是沙箱，也不授予额外 Android 权限。
- 紧急停止会暂停设备操作、取消任务并关闭扩展自动。
- 增加不包含消息正文的分页耗时诊断。未修改已有数据库结构或删除历史。
