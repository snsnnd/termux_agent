# Pocket Agent / 原生界面

平台：Android Java 原生 View，非网页、非终端套壳。设备约束为 HarmonyOS 4.2 / Android API 31。

UI/UX 数据库提供了原生触控、Roboto、青绿强调色和微交互的建议；其中落地页营销布局不适用于本 App，未采用。
实际界面使用 Android 系统字体、浅/深两套语义色、48dp 最小触控目标和 8dp 间距体系。

- 840dp 以上：左侧会话与导航，右侧有最大阅读宽度的工作区。
- 小屏：顶部三项导航，底部固定输入区；支持键盘抬升和旋转保存输入草稿。
- 对话显示任务状态、流式回复、可展开工具记录、逐步操作确认。
- 文件页支持私有工作区浏览、文本编辑和系统文件选择器导入。
- 设置页提供模型、密钥、隐私同意、无障碍入口、控制开关、基础导航确认策略、记忆整理和会话导出。
- 紧急停止同时取消任务并暂停设备操作，不声称能够回滚已执行动作。

交互不依赖装饰动画；没有外部字体、图片、统计 SDK 或 WebView。大字体和小屏适配仍需实机验证。
